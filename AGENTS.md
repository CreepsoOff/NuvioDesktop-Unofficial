# Nuvio Desktop - Agent Instructions

## Cursor Cloud specific instructions

### Overview

Nuvio is a Kotlin Multiplatform (KMP) + Compose Multiplatform app targeting **Desktop (Windows/macOS)** on the `windows-experimental` branch. It also retains Android/iOS targets. On Linux Cloud VMs, the **Desktop JVM target** can be compiled, tested, and run (with software-rendered UI). Full Windows native packaging requires a Windows host.

### Environment

- **Android SDK** at `/opt/android-sdk` (needed because `build.gradle.kts` includes Android target)
- **JDK 21** pre-installed
- `local.properties` at project root with `sdk.dir=/opt/android-sdk` and API secrets (auto-generated by update script from env vars)
- Secrets available as env vars: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `TRAKT_CLIENT_ID`, `TRAKT_CLIENT_SECRET`, `TRAKT_REDIRECT_URI`
- The `mediamp` git submodule must be initialized: `git submodule update --init mediamp`

### Key Commands (Desktop target)

| Action | Command |
|--------|---------|
| Compile Desktop Kotlin | `./gradlew :composeApp:compileKotlinDesktop -x :mediamp:mediamp-mpv:configureCMakeDesktop -x :mediamp:mediamp-mpv:buildCMakeDesktop` |
| Run Desktop app (dev) | `./gradlew :composeApp:run -x :mediamp:mediamp-mpv:configureCMakeDesktop -x :mediamp:mediamp-mpv:buildCMakeDesktop` |
| Run Desktop unit tests | `./gradlew :composeApp:desktopTest -x :mediamp:mediamp-mpv:configureCMakeDesktop -x :mediamp:mediamp-mpv:buildCMakeDesktop` |
| Run Android lint | `./gradlew :composeApp:lintPlaystoreDebug` |
| Build Android APK | `./gradlew :composeApp:assemblePlaystoreDebug` |

### Critical: CMake exclusion flags

The `mediamp-mpv` submodule has native CMake tasks (`configureCMakeDesktop`, `buildCMakeDesktop`) that build a JNI bridge to libmpv. This **only works on Windows/macOS** because `CMakeLists.txt` has `FATAL_ERROR` for Linux. You **must** always pass `-x :mediamp:mediamp-mpv:configureCMakeDesktop -x :mediamp:mediamp-mpv:buildCMakeDesktop` when running any Desktop-related Gradle task on Linux.

### Gotchas

- **Skiko rendering**: On Linux VMs, the app logs `Cannot create Linux GL context` and falls back to software rendering. The UI still displays correctly via Skiko's fallback path. Mesa GL libraries (`libgl1-mesa-dri`, `libgl1`) should be installed for the fallback to work.
- **No media playback on Linux**: The MPV native library (`.dll`) is Windows-only. The app runs fine for all non-playback flows (auth, navigation, library, search, settings).
- **`local.properties` is .gitignored** and `AGENTS.md` is also in `.gitignore`. Use `git add -f AGENTS.md` to commit this file.
- **Build configuration resolves secrets from env vars first**, then `local.properties`, then `release.properties` (see `GenerateRuntimeConfigsTask.resolveRuntimeValue`).
- **Version info** comes from `iosApp/Configuration/Version.xcconfig` — single source of truth for all platforms.
- **Gradle configuration cache** is enabled. Add `--no-configuration-cache` if you hit cache issues after modifying `build.gradle.kts`.
- The `full` Android flavor requires QuickJS `.aar` files in `composeApp/libs/`. Use `playstore` flavor for simpler builds.
- The `mediamp` composite build is auto-included only when the submodule is properly initialized (checked by `settings.gradle.kts`).
- **DISPLAY variable**: When running the Desktop app GUI, set `DISPLAY=:1` so Skiko can render to the virtual framebuffer.
- **Android lint has pre-existing errors**: `lintPlaystoreDebug` reports MissingPermission and NewApi issues in the existing codebase. This does not indicate a setup problem.
- **First Gradle run is slow** (~5 min) due to dependency downloads and configuration cache creation. Subsequent runs are much faster (~30s for incremental compiles).
